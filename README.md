# Hi, I'm Dion 👋

Software developer at [Greenchoice](https://www.greenchoice.nl) in the Netherlands.
I build tools for photographers and outdoor people, and I run my own infrastructure at home.

## What I'm working on

### 📸 [Starsky](https://github.com/qdraw/starsky) · open source
Find and organize photos using their metadata, and browse and search them in your
own cloud. Backend in **C# / .NET** with a **React** web UI, shipped as a Docker image.
Native desktop apps: **WPF** on Windows and **SwiftUI** on macOS.
[Live demo](https://demo.qdraw.nl) · [Docs](https://docs.qdraw.nl)

### 🥾 [TrailTrackr](https://trailtrackr.eu) · closed source
Native mobile app for tracking your trails, available on iOS and Android.
Built with **Swift** (iOS) and **Kotlin** (Android).
Not public, but happy to talk about it.

### 🏠 Homelab · closed source
My self-hosted setup, running on **k3s** (lightweight Kubernetes) and provisioned
with **Ansible**, so the whole thing is reproducible from code.
