# Hi, I'm Dion 👋

I'm a senior .NET developer from the Netherlands with 10+ years of C#, ASP.NET,
Azure, Docker and Kubernetes behind me. Currently at
[Greenchoice](https://www.greenchoice.nl), where I also work on agentic AI.
Before that I was at iO, on projects for Eneco, Achmea and Centraal Beheer.

At work I care about clear APIs, tests, docs and good code reviews. Outside work
I build tools for photographers and outdoor people, and I run my own
infrastructure at home.

## What I'm building

### 📸 [Starsky](https://github.com/qdraw/starsky) · open source
Find and organize photos using their metadata, then browse and search them in
your own cloud. Backend in **C# / .NET**, **React** web UI, shipped as a Docker
image, with native desktop apps: **WPF** on Windows and **SwiftUI** on macOS.
[Live demo](https://demo.qdraw.nl) · [Docs](https://docs.qdraw.nl)

### 🥾 [TrailTrackr](https://trailtrackr.eu) · closed source
A native mobile app for tracking your trails, on iOS (**Swift**) and Android
(**Kotlin**). The code isn't public, but I'm happy to talk about how it's built.

### 🏠 Homelab
My home setup runs on **k3s** and is provisioned with **Ansible**, so I can
rebuild the whole thing from code.
